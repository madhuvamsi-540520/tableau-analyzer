Accessibility rules

  • All text/background combinations must meet WCAG AA: 4.5:1 for body text, 3:1 for large text and UI boundaries.
  • Light-mode green (--green / --green-bright) is never used as text or small labels — contrast against white fails. Use teal (--accent) for light-mode links and text instead.
  • Never remove focus indication. Every interactive element gets a 2px --focus-ring outline, 2px offset.
  • Charts default to neutral gray; reserve the accent color for the one series that matters. Sequential data uses the teal→green ramp (#0A3645 → #0F6D6B → #06E478), never a rainbow scale.
